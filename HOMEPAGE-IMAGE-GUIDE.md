# HnH Wood Studio — Homepage Image Guide

Use this as the upload checklist for the homepage. The website is already wired to these paths, so replacing the files with the final photography should require no layout work.

## Photography direction

- Warm, natural, premium furniture photography.
- Real furniture in believable interiors; avoid stock-looking CGI where possible.
- Soft daylight / warm architectural lighting.
- Neutral walls and uncluttered styling so the furniture remains the subject.
- No visible text, logos, watermarks, people posing for the camera, or busy backgrounds.
- Keep important furniture details away from the extreme edges because some slots crop responsively.
- Prefer high-resolution JPG/WebP. Aim for roughly 2000–3000 px on the long edge.
- Keep files reasonably compressed; target roughly 300–700 KB each when practical.

## Crop-safe rules

The site uses responsive `object-cover` crops in several sections.

For every image:
1. Keep the main furniture piece inside the central ~70% of the frame.
2. Do not put the important face/edge/detail right against the border.
3. Avoid extremely wide compositions for 4:5 slots.
4. Avoid extremely tall compositions for the 16:10 room slots.
5. Photograph slightly wider than the final crop when possible.

## Upload order

If uploading in batches, use this order:

1. Hero + Featured Pieces
2. Room images
3. Gallery images
4. Material images
5. Craft image
6. Personal-room images
7. Journal images
8. Studio detail

Once the final files exist at these exact paths, the homepage should automatically pick them up.
